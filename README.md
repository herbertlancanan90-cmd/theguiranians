# The Guiranians — school publication PWA

## Preview
Open `index.html` in a browser. For full PWA/service-worker support, serve this folder through a local or hosted HTTP server.

## Included
- Responsive Home, Feature Stories, and Editorial Cartooning pages
- Attached publication logo
- Poppins typography and vibrant school colors
- Placeholder stories and editorial-cartoon concepts
- Demo CMS for adding, editing, and deleting stories/cartoon entries
- Local browser storage and basic PWA manifest/service worker

## CMS limitations
This is a front-end prototype. CMS changes are stored only in the current browser/device using localStorage. It does not have logins, a shared database, image uploading, or multi-editor publishing. Image fields accept publicly accessible image URLs. For a live school publication shared across devices, connect a secure backend/CMS and configure hosting.

All article copy and cartoon descriptions are placeholders. Verify facts, obtain school approval, and secure consent for identifiable learner photos before publication. No payment features are included.
